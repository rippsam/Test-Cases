# [Example for Students] Login with valid credentials

---

## Description
Test the login page using a valid existing username and password. (This test case was used as an example for students who were learning how to make test cases).

---

## Preconditions
1. Existing valid user that can login.
2. Be on the login page

---

## Test Steps

| # | Step | Expected Result |
|---|------|-----------------|
| 1 | Verify login page components. | Only a login box, username field, password field, the word Login at top and login button, should be visible and usable. |
| 2 | Select username field. | Cursor appears in input and username text persists. |
| 3 | Input a valid username. | Username placeholder text disappears upon first character typed. Username is visible. |
| 4 | Select password field. | Cursor appears in input and password text persists. |
| 5 | Input a valid password that is paired with the username input in step 3. | Password placeholder text disappears upon first character typed and as the user is typing in password the password characters become dots so that the characters are not visible. |
| 6 | Select Login button. | Home page loads. |
